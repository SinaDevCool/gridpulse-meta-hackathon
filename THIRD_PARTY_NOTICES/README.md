Original GridPulse code is MIT licensed. Dependencies installed from the lockfiles retain their own licences. The generated MapLibre worker assets are covered by the accompanying MapLibre BSD licence. Existing source headers, source attribution, data provenance and licence metadata are preserved in both snapshots.

Public map/network datasets and third-party visual assets are not relicensed by the root MIT licence. Review their accompanying source/attribution records before redistribution or a new use. This source release excludes tracked CVs, investor documents, office/PDF files, output folders, local credentials and Git history.
