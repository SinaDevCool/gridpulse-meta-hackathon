# Meta hackathon submission requirements

Verified on 28 October 2026 from the signed-in [participant guide](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/details). This checklist records requirements; it does not accept legal terms or submit a project.

| Requirement | GridPulse delivery action |
| --- | --- |
| Incorporate Meta models | Demonstrate actual Meta interpretation and verified-finding selection, with provider receipts |
| Existing startup products permitted | Identify the pre-event GridPulse baseline separately from the changes made during the event |
| Present only new event contributions | Centre the video on verified claims, corrected experiment lifecycle, stage receipts and investigation export; use the existing planner only as context |
| Public repositories | Prepare and review a source package. Do not change private repository visibility or publish private source without explicit approval |
| Three-minute demo video | Prepare a new three-minute recording; the earlier AI Pioneers video is not the final hackathon video |
| Maximum four team members | List only actual contributors and confirm the accepted track |
| One submission per team/startup | Sina acts as representative if confirmed; do not submit duplicates |
| Publicly accessible repository and video links | Verify links from a fresh unauthenticated session after publication is authorised |
| Deadline 4 November, 9 PM Eastern | Berlin equivalent: 5 November, 3 AM; submit earlier and retain the portal receipt |

The guide states the building period as 27 October to 4 November, while the general event page lists a 26 October kickoff. The changes in this candidate began on 28 October. Retain the exact starting commit and dated contribution evidence rather than relying on the earlier broader product history.

Judging weights in the guide are impact 30 percent, Meta tooling 25 percent, technical depth/execution 20 percent and demo 25 percent. It excludes generic basic RAG projects. The submission should therefore demonstrate an evidence-bound investigation with actual calculations and failure handling, rather than describe GridPulse as a document chatbot.

Remaining checks: accepted track, final portal fields, any separately applicable official agreement, public-source publication approval, video hosting destination and successful submission receipt. Reading the guide does not authorise posting, legal acceptance, visibility changes or uploads.
