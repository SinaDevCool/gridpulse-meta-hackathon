# Independent expert review rubric

Score each criterion from 0 (unacceptable) to 3 (pilot ready), and record evidence for the score.

| Criterion                   | Review question                                                                                           |
| --------------------------- | --------------------------------------------------------------------------------------------------------- |
| Product truth               | Could any statement be mistaken for confirmed capacity, a connection offer or an energisation commitment? |
| Operator routing            | Is responsibility clearly screened versus confirmed?                                                      |
| Technical completeness      | Are load, voltage, protection, redundancy and single-line-diagram requirements visible?                   |
| Flexibility realism         | Are critical load, event duration, notice, recovery, storage and workload constraints credible?           |
| Calculation reproducibility | Can the reviewer reproduce the result from the recorded profile and settings?                             |
| Minimum viable service      | Does the product reject configurations below the declared operating floor?                                |
| Evidence provenance         | Does every material conclusion identify its source class and validation status?                           |
| Operator usefulness         | Are questions specific enough to support a real pre-application discussion?                               |
| Decision usefulness         | Does the comparison change or strengthen the next decision?                                               |
| Commercial usefulness       | Would the customer pay to repeat this process on another project?                                         |

Pilot readiness requires no zero scores and explicit resolution owners for all scores below 2.
