# Pilot-learning implementation

## Objective

Turn GridPulse from a static grid-context map into an evidence-led decision workflow that learns only from consented, attributable outcomes.

## Implemented workflow

1. Scheduled source monitoring records every official endpoint check, content hash, HTTP metadata, error, and detected change.
2. Project alerts persist in an in-app inbox; warning and critical alerts create an email-ready delivery item.
3. Teams capture immutable, hashed decision snapshots at site selection, submission, operator response, and final outcome.
4. The existing pilot case records baseline, interim, and final outcome observations without overwriting history.
5. Management reporting aggregates portfolio exposure and benchmarks only eligible, customer-confirmed pilots.
6. The operator onboarding register makes source discovery, reuse rights, and next actions explicit.

## Truth and consent boundaries

- Public network context is not available connection capacity.
- Derived metrics are not a connection probability.
- Email deliveries remain pending until an approved provider and sender are configured.
- Operator benchmarks exclude pilots without anonymised-case permission.
- A final observation must be customer-confirmed before it enters a benchmark.
- Written operator evidence controls capacity, cost, reinforcement, and timing claims.
